# Thiệp chúc mừng ngày 20/10

Website thiệp 20/10 tương tác, chỉ dùng **HTML và CSS** (không JavaScript).

## Chạy thử
Mở `index.html` bằng trình duyệt.

## Tương tác
- Đổi 3 tông màu: hồng rượu, vàng nắng, tím lavender
- Chạm con dấu để mở/đóng phong bì (nắp lật, confetti)
- Chạm hoa trên thiệp để nở và hiện lời nhắn
- 4 tab: lật thiệp lời chúc, mở hộp quà, trồng vườn hoa, mở bí mật
- Chọn 1–5 trái tim cho “mức độ yêu thương”
- Hover ảnh polaroid để dựng thẳng
- Nút ♪ góc phải: nốt nhạc bay

## Tùy chỉnh lời chúc
Sửa các đoạn trong `index.html` (thiệp lật, hộp quà, phần bí mật).
